# Локальные изображения

Поместите сюда утверждённые фотографии заведения (например, `hero.webp`, `interior-01.webp`, `cocktail-01.webp`). Перед запуском замените внешние демонстрационные URL в `index.html`, `css/style.css` и `data/menu.json` на относительные пути к вашим файлам. Не загружайте фото, на использование которых у вас нет прав.
